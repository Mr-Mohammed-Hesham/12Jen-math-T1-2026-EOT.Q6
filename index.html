📐 القانون العام

الصيغة:
x = (-b ± √(b² - 4ac)) / 2a
للمعادلة ax² + bx + c = 0
المميز (Discriminant):
Δ = b² - 4ac
Δ > 0: حلان حقيقيان | Δ = 0: حل واحد | Δ < 0: لا حلول حقيقية
خطوات الحل:
1. حدد a, b, c
2. احسب المميز Δ
3. طبّق القانون
4. بسّط النتيجة
أمثلة:
x² + 8x + 16 = 0 → a=1, b=8, c=16
2x² + 6x - 7 = 0 → a=2, b=6, c=-7
